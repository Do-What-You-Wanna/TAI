## 1. 任务概述

## 2. 完成情况与交付物

### `gui/theme.py` — QSS 样式表升级
- 基础字号从 13px 提升到 14px，行高/内边距全面加大，提升可读性。
- 分区标题（section label）增至 15px 粗体，品牌色左竖线加宽到 4px，更醒目。
- 标签页 padding 加大，字号 14px，选中态更突出。
- 按钮内边距加宽（8px×18px），输入框 padding 加大（7px×10px），更易点击。
- 表头加粗 + 底部 2px 分割线，斑马纹色 #f8fafc 更柔和。
- 新增 `empty_hint()` 函数：空状态占位提示（斜体灰色居中文字）。
- 新增 `styled_tab_text()` 函数 + `TAB_ICONS` 映射：标签页图标前缀。
- 新增状态栏色块 QSS（ok=绿/warn=黄/error=红）。

### `gui/app.py` — 界面结构升级
- **标签页图标**：◆工作台、▣模型管理、⚙规则配置、◴任务历史、✦设置。
- **居中约束**：主内容最大宽度 960px，两侧弹性留白居中，大屏不再拉满。
- **空状态提示**：
  - 工作台：「尚未运行任务，在上方输入任务后点击「运行」」
  - 模型管理：「尚未添加模型，点击下方「新增」按钮开始」
  - 任务历史：「暂无任务历史，运行任务后将自动记录」
- **状态栏色块**：绿色 ● 色块表示就绪，支持 ok/warn/error 三态切换。

### 验证结果
- 离屏构建 5 个标签页，图标前缀正确（◆/▣/⚙/◴/✦）。
- 居中约束 maxWidth=960 生效。
- 工作台空状态提示可见（无数据时），模型管理/历史正确隐藏（有数据时）。
- 状态栏色块 property="ok" 生效。
- 无异常退出。

## 3. 发现的问题 / 不足 / 风险
1. **QSS 不支持动态真投影**：卡片用浅底+圆角近似，无阴影立体感（可接受）。
2. **图标依赖字体**：Unicode 几何符号在极少数字体下可能缺失，但 Segoe UI/YaHei 均覆盖。
3. **居中约束对小屏**：最小宽度 640px，小于此宽度的窗口会出现横向滚动（影响极小）。
4. **状态栏色块静态**：目前仅显示 ok 态，实际连接检测逻辑待后续接入。
