## 1. 任务概述
对正式版桌面界面进行整体视觉与体验优化，方向为：现代浅色主题、全应用统一风格、

## 2. 完成情况与交付物
- 新增 `gui/theme.py`：统一 QSS 样式表 `APP_QSS` + `make_button`/`section_label` 辅助。
  - 品牌色 #3b82f6，浅灰底 + 白色圆角卡片，柔和边框，现代分层。
  - `danger`/`ghost` 两种按钮对象名样式；输入框 focus 高亮；表格斑马/表头/滚动条统一样式。
- `gui/app.py` 全面接入：
  - 主窗口应用全局主题。
  - 工作台：输入区/状态/分配表统一留白，按钮加图形符号（▶运行、⏹中止），隐藏行号、斑马纹。
  - 模型管理：图标按钮（＋新增/✎更新/✕删除/★主模型/✓保存）、删除为危险色、编辑卡片分组。
  - 规则/历史/设置页：分组卡片化、图标按钮、隐藏行号、斑马纹。
- 验证：离屏构建全部 5 个标签页、样式表生效（3041 字符）、按钮对象/文本正确，无异常退出。

## 3. 发现的问题 / 不足 / 风险
1. **QSS 不支持真投影**：卡片用浅底+圆角+细边替代，立体感有限（可接受）。
2. **图形符号跨字体差异**：▶、⏹ 等几何符号在部分 Windows 字体下显示行高略有差异（影响极小）。
3. **超大屏无最大宽度限制**：主内容在大分辨率下仍横向拉满，未做到严格的居中对称上限（可后续加 maxWidth）。
4. **R4 产物待更新**：`dist/Agent.exe` 需重新打包以包含新 UI（本轮已启动后台重新打包）。
