## 3. 发现的问题 / 不足 / 风险
1. **云端模型不可用未体现“专业分工”**：未配置云端 API Key 时，代码/文档类子任务全部回退到本地
   主模型，界面无法展示按专业技能分工的效果（非缺陷，属配置前提，但差旅易误解）。
2. **`Orchestrator._execute_with_fallback` 结果与分配行对齐**：`_on_done` 用 `results[i]` 与
   `assignments[i]` 按顺序回填，回退重分配后二者顺序可能不完全一致，存在显示错位风险（低概率）。
3. **主模型编排在真实 Ollama 缺失模型时**：`route_provider` 仍用主模型进行拆解，若模型缺失会长期
   等待/超时才降级，首次体验欠佳。
4. **打包（里程碑 R4）未进行**：正式版尚未产出可分发 exe，仅有源码运行入口。
5. **模型管理页「更新」用 key 作主键**：修改表格后若 key 被改，`update()` 会抛「模型不存在」，
   体验上应先禁用 key 编辑再做更新（次要）。
6. **`config.py` 的 `models_to_dicts` 未被使用**，属死代码（轻微）。
